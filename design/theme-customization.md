# 早睡系统 · 主题自定义体系（完整版）

> 除了 4 套预设主题，用户还可以自由组合以下所有维度。

## 二、自定义维度详解

### 🎨 维度 1：颜色

| 项目 | 可自定义 | 预设选项 |
|------|---------|---------|
| **主色** | ✅ 色盘自由选 | 紫罗兰 · 暖橙 · 森林绿 · 海洋蓝 · 樱花粉 · 暗红 |
| **背景色** | ✅ 色盘 + 渐变 + 图片 | 深空黑 · 深紫 · 深绿 · 暖白 · 米灰 |
| **卡片色** | ✅ 色盘 + 透明度 | 纯色 · 半透明毛玻璃 · 不透明 |
| **文字色** | ✅ 自动对比度适配 | 随背景自动黑/白 |
| **强调色** | ✅ 色盘选 | 与主色联动或独立设置 |
| **成功/警告/错误色** | ✅ 色盘选 | 绿/黄/红（可换） |

**交互方式：**
```
┌──────────────────────────┐
│  🎨 主色                  │
│                          │
│  ○ ● ○ ○ ○ ○ ○ ○ ○ ○    │  ← 预设色块快速选
│                          │
│  ┌──────────────────┐    │
│  │   自定义 HSL 滑块  │    │  ← 或者拖滑块微调
│  └──────────────────┘    │
│                          │
│  当前: #7170ff           │  ← 也可直接输 hex
└──────────────────────────┘
```

### 🌱 维度 3：虚拟伙伴（与成就系统联动）

| 类型 | 幼年期 | 成长期 | 成熟期 | 解锁条件 |
|------|--------|--------|--------|---------|
| **🌿 植物系** | 🌱 种子 | 🌿 幼苗 | 🌳 大树 | 默认解锁 |
| **🌸 花卉系** | 🌰 种子 | 🌷 花苞 | 🌹 开花 | 连续 7 天 |
| **🌵 沙漠系** | 🌵 小刺球 | 🌵 长高 | 🌵 开花 | 连续 14 天 |
| **🐱 猫咪** | 🐈 小猫 | 🐈 成猫 | 🐱 胖猫 | 连续 7 天 + 宵禁 5 次 |
| **🦉 猫头鹰** | 🪺 蛋 | 🐣 雏鸟 | 🦉 成鸟 | 连续 14 天 + 宵禁 10 次 |
| **🌊 海洋系** | 🪸 珊瑚 | 🐠 小鱼 | 🐋 鲸鱼 | 连续 30 天 |
| **⭐ 星空系** | ✨ 星光 | 🌙 弯月 | 🌌 银河 | 连续 100 天 |

**交互：**
```
每次达标 → 伙伴有成长动画
连续达标 → 伙伴进化形态
未打卡 → 伙伴进入"休眠"状态（不惩罚，但会显示）
```

### 🖼️ 维度 4：背景

| 类型 | 选项 | 说明 |
|------|------|------|
| **纯色** | 任意颜色 | 最简单的自定义 |
| **渐变** | 预设 12 组渐变 | 日落到星空等氛围 |
| **用户照片** | 本地上传 | 自动模糊 + 遮罩 |
| **动效背景** | 星空、落雪、雨滴、萤火虫 | 低功耗，可选 |
| **纹理** | 亚麻、磨砂、噪点、水彩 | 静态叠加 |
| **季节性** | 春/夏/秋/冬 自动切换 | 根据月份 |

---

### 🔊 维度 5：氛围声

| 场景 | 可选声音 | 说明 |
|------|---------|------|
| **睡前** | 雨声 · 海浪 · 森林 · 白噪音 · 篝火 · 钢琴 | 可定时关闭 |
| **起床** | 鸟鸣 · 渐进铃声 · 冥想钟 | 柔和唤醒 |
| **打卡成功** | 叮 · 和弦 · 无声 | 完成反馈 |
| **成就解锁** |  fanfare · bell · chime | 奖励反馈 |

---

### 🔠 维度 6：字体

| 风格 | 示例 | 适合 |
|------|------|------|
| **系统默认** | Inter / SF Pro | 清晰易读 |
| **圆体** | 更柔和 | 温暖可爱风 |
| **衬线** | 更正式 | 高端/日记感 |
| **手写体** | 更个性 | 日记/备注 |
| **等宽** | 科技感 | 数据分析页 |

---

### 📊 维度 7：卡片密度

| 模式 | 描述 |
|------|------|
| **舒适** | 大间距、大字号、适合睡前 |
| **紧凑** | 小间距、更多信息、适合白天看数据 |
| **极简** | 只有核心数据，隐藏次要元素 |

---

### 🎬 维度 8：动画风格

| 风格 | 说明 |
|------|------|
| **流畅** | 默认，适中的过渡动画 |
| **减少动效** | 只保留必要的过渡，省电/防头晕 |
| **趣味** | 弹跳、缩放等更活泼的动画 |
| **无动画** | 切换瞬间完成 |

## 五、技术实现要点

```typescript
// 主题配置数据结构
interface ThemeConfig {
  // 预设标识
  preset?: 'dark-precision' | 'warm-night' | 'nature-calm' | 'minimal-light';
  
  // 颜色
  colors: {
    primary: string;         // 主色
    background: string;      // 背景色
    backgroundGradient?: string[];
    surface: string;         // 卡片色
    surfaceBlur?: number;    // 毛玻璃透明度
    text: string;
    textSecondary: string;
    success: string;
    warning: string;
    error: string;
  };
  
  // 按钮
  button: {
    style: 'rounded' | 'pill' | 'sharp' | 'pet' | 'glow' | 'outline' | '3d';
    petType?: 'cat' | 'bear' | 'owl' | 'star' | 'none';
  };
  
  // 虚拟伙伴
  companion: {
    type: 'plant' | 'flower' | 'cactus' | 'cat' | 'owl' | 'ocean' | 'star';
    currentStage: number;
  };
  
  // 背景
  background: {
    type: 'color' | 'gradient' | 'photo' | 'animated' | 'texture';
    photoPath?: string;
    blur?: number;
    overlay?: number;  // 暗色遮罩强度 0-1
  };
  
  // 声音
  sound: {
    bedtime?: 'rain' | 'ocean' | 'forest' | 'whitenoise' | 'fire' | 'piano' | 'none';
    wakeup?: 'birds' | 'gentle' | 'meditation' | 'none';
    feedback?: 'ding' | 'chord' | 'silent';
  };
  
  // 字体
  font: 'system' | 'rounded' | 'serif' | 'handwrite' | 'mono';
  
  // 密度
  density: 'comfortable' | 'compact' | 'minimal';
  
  // 动画
  animation: 'smooth' | 'reduced' | 'playful' | 'none';
}

// 默认值 = 预设主题 A 的配置
// 用户修改任一维度 → 变为"自定义主题"模式
// 用户可随时重置回预设
```
