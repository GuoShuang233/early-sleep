# 早睡系统 — V6 最终方案

> 2026-07-25 | V6（定稿版）
> 不锁 App、不注册、权限最小化、预留广告位

---

## 一、一句话描述

> **一个不需要注册、不需要奇怪权限的早睡 App。**
> **说一句"我睡了"就打卡，第二天告诉你昨晚几点睡的、睡前刷了什么。看报告时有广告，但你睡觉时不会打扰你。**

## 三、全平台一致方案

### 3.1 功能对照表

| 功能 | iOS | Android | 鸿蒙 | 用户看到 |
|------|-----|---------|------|---------|
| **就寝/起床打卡** | 手动 + Siri | 手动 + App Actions/小爱 | 手动 + 小艺 | ✅ 完全一致 |
| **宵禁检测** | DeviceActivityReport（系统渲染） | UsageStats（直接读取） | 使用统计 API | ✅ 同一排行榜 |
| **睡眠时长** | HealthKit | Health Connect | 运动健康 | ✅ 完全一致 |
| **App 锁定** | ❌ 已移除 | ❌ 已移除 | ❌ 已移除 | — |
| **语音打卡** | Siri Shortcuts | App Actions | 小艺 | ✅ 完全一致 |
| **成就系统** | 本地计算 | 本地计算 | 本地计算 | ✅ 完全一致 |
| **广告位** | ✅ 报告页+周报 | ✅ 报告页+周报 | ✅ 报告页+周报 | ✅ 完全一致 |
| **AI 建议** | 统计+Core ML | 统计+ML Kit | 统计分析 | ✅ 完全一致 |

### 3.2 权限链路（优化后）

```
安装 → 打开 App

  📱 首次打卡"准备睡觉"
      第一次使用时才问 ↓
      🔔 通知权限："到点提醒你睡觉"
   
  ☀️ 第二天起床想看结果  
      需要宵禁数据时才问 ↓
      📊 使用统计权限："看看昨晚睡了后有没用手机"
   
  💤 想查看系统睡眠数据（可选）
      用户主动选择 ↓  
      ❤️ 健康数据权限："读取睡眠记录"
```

**只有 3 个权限，全部是"用到的时候才问"，不需要去系统设置里翻。**

### 3.3 不需要的（已移除）

| 之前考虑过 | 原因 |
|-----------|------|
| ❌ 账号注册 | 纯本地，不需要 |
| ❌ Shield App 锁定 | 不用了 |
| ❌ 传感器（加速度计等） | 只用系统日志，不主动监听 |
| ❌ 麦克风 | 不录音 |
| ❌ 定位 | 无关 |
| ❌ 网络权限 | 除了广告不需要网络 |

## 四、晨间睡前习惯报告（核心功能）

每天早上用户点"我起床了"后：

```
┌──────────────────────────────────────────────┐
│  ☀️ 早上好！                                  │
│                                               │
│  🌙 昨晚                                    │
│  就寝：23:15         起床：07:30              │
│  睡眠：7h38m         宵禁：✅ 达标            │
│                                               │
│  📱 睡前 App 排行                              │
│  ① 抖音      1h20m  ████████████████████      │
│  ② 微信       45m   ██████████                │
│  ③ 小红书      8m   ██                        │
│                                               │
│  💡 建议                                      │
│  「你打卡后又刷了半小时手机。」                  │
│  「今晚试试打卡后直接把手机放客厅？」            │
│                                               │
│  🔥 连续 3 天 · 宵禁达标率 67%                 │
│                                               │
│  [广 告 位] — 你的早晨由 XXX 陪伴              │
│                                               │
│  [查看周报]           [分享成就]               │
└──────────────────────────────────────────────┘
```

**数据来源：**
- iOS：HealthKit（睡眠）+ DeviceActivityReport（App 排行·系统渲染）
- Android：Health Connect（睡眠）+ UsageStats（App 排行·直接读取）

**UI 完全一致**——底层数据源不同，但同一套卡片布局。

## 五、广告位设计

### 5.1 广告位置

| 位置 | 形式 | 说明 | 预期收入价值 |
|------|------|------|------------|
| **🏠 首页底部** | 原生 Banner | 嵌入风格的小卡片，标注"赞助" | 低（展示量） |
| **📊 晨间报告底部** | 原生 Banner | 看完数据往下滑时自然看到 | 中（日活曝光） |
| **📈 周报/月报页面** | 原生卡片 | 报告分析下方的赞助卡片 | 中（周活曝光） |
| **🏆 成就解锁（可选）** | 激励视频 | "看广告解锁新主题/勋章" | 高（用户主动点） |
| **🎨 主题/皮肤页面** | 激励视频 | "看广告解锁新配色" | 高（用户主动点） |

### 5.2 广告位原则

```
✅ 睡前流程中不放任何广告
✅ 不用弹窗广告
✅ 不用全屏插屏广告
✅ 不干扰打卡操作
✅ 原生样式，融入 UI，不破坏体验

广告只在"用户在阅读报告/浏览数据"时出现
——那个场景下用户有心理余裕，不反感
```

### 5.3 技术预留

```
React Native 插件：
  · iOS：Google AdMob 或 Apple Search Ads
  · Android：Google AdMob
  · 以原生 Banner 和激励视频为主
  
代码层面：
  · 广告组件独立封装，可随时开关
  · 广告位用占位组件，有广告就展示，没有就隐藏
  · 不影响 App 核心功能
```
