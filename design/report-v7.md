# 早睡系统 — V7 最终方案报告

> 2026-07-26 | V7（设计定稿版）
> React Native · Android + iOS + 鸿蒙

---

## 一、产品定位

> **一个不需要注册、不需要奇怪权限的早睡 App。**
> **说一句"我睡了"就打卡，系统自动检测你有没有偷玩手机，第二天告诉你昨晚几点睡的、睡前刷了什么。**
> **8 个维度自由定制主题，3 种广告位创收。**

---

## 三、功能总表

### 3.1 核心功能

| 功能 | 说明 |
|------|------|
| **就寝打卡** | 点"准备睡觉"或语音（Siri/小爱）记录 |
| **起床打卡** | 点"我起床了"结束睡眠记录 |
| **宵禁检测** | 系统日志读取，不主动监听 |
| **晨间报告** | 就寝/起床/睡眠时长/宵禁/App 排行/建议 |
| **备注功能** | 睡前填写加班/应酬/失眠等，分析时豁免 |
| **日历视图** | 三色标记：达标/有备注/熬夜 |
| **成就系统** | 连续天数、宵禁、植物成长里程碑 |
| **本地 AI 分析** | 统计趋势 + 模式发现 + 个人化建议 |

### 3.2 主题自定义（8 个维度）

| 维度 | 内容 | 选项 |
|------|------|------|
| 🎨 **颜色** | 主色/背景/卡片/文字 | 色盘选 + HSL 滑块 + hex 输入 |
| 🎪 **按钮风格** | 样式 + 宠物造型 | 圆角/胶囊/直角/发光/描边/3D + 猫爪/熊掌/猫头鹰/星星 |
| 🌱 **虚拟伙伴** | 随成就进化的伙伴 | 植物/花卉/仙人掌/猫咪/猫头鹰/海洋/星空 |
| 🖼️ **背景** | 皮肤级自定义 | 纯色/渐变/照片/动效/纹理/季节 |
| 🔊 **氛围声** | 睡前/起床/反馈音效 | 雨声/海浪/森林/白噪音/篝火/钢琴/鸟鸣 |
| 🔠 **字体** | 阅读体验 | 系统/圆体/衬线/手写/等宽 |
| 📊 **卡片密度** | 信息密度 | 舒适(睡前)/紧凑(白天)/极简 |
| 🎬 **动画风格** | 过渡动效 | 流畅/减少动效/趣味弹跳/无动画 |
| 📤 **主题分享** | 导出/导入 | JSON 格式，可供分享 |

**4 套预设主题：**
- **A. Dark Precision** — Linear 风格深色精确（夜晚默认）
- **B. Warm Night** — 深紫渐变暖色助眠
- **C. Nature Calm** — 绿植自然风
- **D. Minimal Light** — 暖白亮色极简（白天默认）

**自动切换：** 6:00-18:00 自动 D → 18:00-6:00 自动 A

### 3.3 广告位（3 种形式）

| 形式 | 位置 | 说明 |
|------|------|------|
| **Banner** | 晨间报告底部、设置页底部 | 横条展示，不干扰操作 |
| **视频/音频** | 成就页底部 | 展示型广告，用户无需互动 |
| **原生信息流** | 日历页、周报数据流 | 外观与列表一致，标注"广告" |

**规则：** 睡前流程不放广告、不用弹窗、不用全屏插屏。

## 四、权限链路

```
安装 → 打开 App

  📱 首次打卡"准备睡觉"
      ↓ 第一次使用时才问
  🔔 通知权限："到点提醒你睡觉"

  ☀️ 第二天起床想看结果
      ↓ 需要宵禁数据时才问
  📊 使用统计权限："看看昨晚睡了后有没用手机"

  💤 想查看系统睡眠数据（可选）
      ↓ 用户主动选择
  ❤️ 健康数据权限："读取睡眠记录"
```

**只有 3 个权限，全部是"用到的时候才问"，不需要去系统设置里翻。**

## 五、平台技术方案

| 项目 | 方案 |
|------|------|
| 跨平台框架 | React Native（Android + iOS） |
| 鸿蒙 | 后续单独 ArkTS（复用设计稿） |
| 本地存储 | SQLite |
| 主题系统 | ThemeContext + JSON 配置 |
| 广告 | AdMob（Banner + 原生） |
| 宵禁检测(iOS) | DeviceActivityReport（系统渲染） |
| 宵禁检测(Android) | UsageStatsManager |
| 睡眠数据(iOS) | HealthKit |
| 睡眠数据(Android) | Health Connect |
| 语音 | Siri Shortcuts / App Actions |
| 主题持久化 | AsyncStorage |
