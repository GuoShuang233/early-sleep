## Variant: Warm Night (暖色助眠风)

### 设计立场
深紫暖色调——像夜晚的烛光，温柔、安神。适合睡前使用的氛围。

### 关键选择
- **背景**: 深紫渐变 `#120c1a` → `#1e1630`
- **主色**: 淡紫 `#b8a0e0` / 暖橙 `#f0b888`
- **成功色**: 浅蓝 `#88c8e8`
- **卡片**: 半透明毛玻璃效果，圆润
- **圆角**: 放大到 18-20px，更柔和
- **字体**: Inter，颜色偏暖灰
- **氛围**: 温暖、舒适、助眠

### 视觉增强
- 背景左右有辉光光晕（径向渐变）
- 小圆点带发光阴影
- 渐变文字标题
- 整体更像"睡前放松工具"而非"数据仪表盘"

### 适合场景
- 偏好温暖、有氛围感的用户
- 睡前使用时不刺眼
- 适合"这是帮你放松的工具"定位
