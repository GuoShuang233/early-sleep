## Variant: Dark Precision (冷色精确风)

### 设计立场
Linear 启发的深色极简风格——近黑背景、紫色主色、精确排版。像工具一样冷静、可靠。

### 关键选择
- **背景**: `#08090a` 近黑（Linear 风格）
- **主色**: 紫罗兰 `#7170ff` / `#5e6ad2`
- **成功色**: 翡翠绿 `#10b981`
- **卡片**: 半透明白色背景，极细边框
- **圆角**: 标准 14px，放大按钮 16px
- **字体**: Inter，数字用加粗强调
- **氛围**: 精确、高质量工具感

### 适合场景
- 偏好看"干净利落"工具风格的用户
- 重视数据可读性
- 适合"这是个严肃的习惯追踪器"定位
